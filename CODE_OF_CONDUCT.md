# Code of conduct

We welcome contributions from people of any background or experience level.
Treat participants respectfully, focus criticism on the work, and help make
questions and contributions useful to others.

Harassment, threats, discrimination, personal attacks, doxxing, and publishing
someone else's confidential information are not acceptable. Do not pressure
contributors to reveal personal data or provide unpaid work on a deadline.

These expectations apply to this repository's issues, pull requests, reviews,
and other project spaces. Maintainers may remove inappropriate content, close
disruptive discussions, or restrict participation, taking context and severity
into account. Maintainers are also expected to follow these rules.

For a conduct concern, contact the maintainer through the public GitHub profile
at https://github.com/daniilpet. If no suitable private channel is listed, open
an issue requesting a private contact without naming people or describing
sensitive details publicly. Security vulnerabilities use [SECURITY.md](SECURITY.md).
